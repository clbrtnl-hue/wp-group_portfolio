TEAM PORTFOLIO — STANDALONE WORDPRESS PARENT THEME (VERSION 1.1.0)

This is a complete standalone WordPress theme. It is NOT a child theme and does
NOT require Twenty Twenty-Four to be installed or activated.

INSTALLATION
1. In WordPress, go to Appearance > Themes > Add New > Upload Theme.
2. Upload team-portfolio-parent-theme-v1.1.zip and click Install Now.
3. Activate Team Portfolio (v1.1).
4. Open the WordPress Dashboard once. The theme automatically creates the
   Chloe, John Bryan, and Keziyah portfolio pages if they do not already exist.
5. Go to Settings > Permalinks and click Save Changes once if links do not open.
6. Visit the group homepage and click each member card to test the pages.

INCLUDED PROJECT STARTER ENTRIES
- OPCR & IPCR Monitoring System
- Hotel Management System
- Quiz Game

NOTES
- Project descriptions for Hotel Management System and Quiz Game are starter
  copy only. Replace them with your actual project scope, features, stack, and
  contributions before presenting the portfolio.
- Personal information that has not been confirmed remains editable starter
  copy or clearly marked fields. Update it with each member's own details.
- Contact forms prepare a message in the visitor's email application; they do
  not send mail directly without a mail/backend integration.
- Add actual profile photos, social URLs, and resume PDFs before publishing.
